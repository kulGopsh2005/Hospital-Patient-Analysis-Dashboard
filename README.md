# Hospital Patient Analysis Dashboard

## 📊 Project Overview

This project is an **Hospital Patient Analysis Dashboard** created using **Microsoft Excel** to analyze and visualize hospital patient data.

The dashboard provides an interactive overview of patient demographics, medical conditions, procedures, costs, readmissions, length of stay, patient outcomes, and satisfaction levels.

## 🏥 Dashboard Features

- Total Patient Count
- Average Patient Age
- Average Length of Stay
- Average Patient Satisfaction
- Gender-wise Patient Analysis
- Age Group Analysis
- Medical Condition Analysis
- Procedure-wise Cost Analysis
- Readmission Analysis
- Patient Outcome Analysis
- Length of Stay Distribution
- Patient Satisfaction Analysis
- Interactive Slicers for filtering the dashboard

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- **Pivot Tables**
- **Pivot Charts**
- **Power Query**
- **Excel Slicers**
- **Data Cleaning & Transformation**
- **Data Analysis & Visualization**

## 📈 Key Insights

The dataset contains **984 patient records** covering different age groups, genders, medical conditions, procedures, treatment costs, readmission status, outcomes, and satisfaction levels.

The analysis helps identify patterns in:

- Patient demographics
- Common medical conditions
- Treatment procedures
- Average treatment costs
- Patient readmissions
- Length of hospital stay
- Patient outcomes
- Patient satisfaction
